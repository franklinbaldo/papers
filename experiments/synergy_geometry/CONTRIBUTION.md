# Synergy–Geometry contribution boundary

The programme does **not** claim novelty for composition, non-additivity, binding, emergent features, PID synergy, layerwise composition, activation patching, or cross-model representation alignment.

A contribution exists only if prospective experiments support the conjunction:

> a purified interaction component carries relation information beyond matched marginal/nonlinear controls, generalizes to unseen factor combinations, is selectively causal for relation-dependent behavior, and shows above-null correspondence across independently trained model families under alignment calibrated without confirmatory interaction pairs.

PID synergy is an additional independently measured axis. Coupling between synergy, geometry and causal efficacy would strengthen the result but is not assumed.

If a prior paper is found that already establishes the same conjunction under materially equivalent controls, the novelty claim must be narrowed or surrendered even if all experiments pass.
