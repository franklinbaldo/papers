# Preregistration amendment — contextual token cache for Few-NERD NER

Date: 2026-09-15

This amendment is recorded before the first semantic-embedding execution for the Few-NERD front. It supersedes the implementation detail in `preregistered-fewnerd-ner-multiscale-byte-spans-2026-09-15.md` that proposed independently encoding every contiguous span.

## Motivation

Few-NERD contains millions of tokens. Independently invoking MiniLM/E5 for every overlapping span at scales 1, 2, 4 and 8 would multiply frozen-encoder work and cache volume without being necessary to preserve a positional multiscale input field.

The scientific target is the complete NER method and its positional semantic evidence, not repeated invocation of the frozen encoder as an end in itself.

## Frozen semantic-cache construction

For each official Few-NERD sentence and each frozen semantic encoder:

1. reconstruct the sentence by joining official tokens with one ASCII space, exactly as in the byte-axis amendment;
2. run the frozen encoder contextually over the sentence;
3. align encoder subword offsets back to each official Few-NERD token;
4. mean-pool overlapping non-special subword hidden states into one contextual vector per official token;
5. persist those token vectors with sentence id, token index, official token text, encoder identity/revision, dataset/config/split provenance and numeric dtype.

MiniLM and E5 remain separate native channels. E5 uses its documented passage prefix; alignment accounts for the prefix offset.

## Multiscale fields

The cached token vectors are the only expensive frozen-encoder product. Receptive-field channels are derived deterministically from them:

- scale 1: the token vector itself;
- scale 2, 4 and 8: mean of a deterministic local token window of that maximum width containing the target token, clipped at sentence boundaries.

For even widths, allocate the extra token to the right: `left=(width-1)//2`, `right=width-left-1`.

Each resulting scale remains a distinct channel. Its vector is broadcast over the UTF-8 byte interval of the target official token. Separator-space bytes receive no entity target and may receive zero semantic input unless a later preregistered experiment states otherwise.

The byte-local channel is not generated by MiniLM/E5. It is the existing byte-local input representation of the MaleCNS method and remains distinct from frozen semantic channels.

## Efficiency accounting

Report separately:

- cold encoder wall time per model;
- number of sentences/tokens encoded;
- encoder throughput;
- cache bytes on disk;
- cache dtype;
- peak RAM/VRAM;
- warm multiscale-field construction time;
- MaleCNS training/inference time.

Embedding/cache generation may be sharded independently by encoder and sentence ranges. Shards must have deterministic provenance and concatenate without changing vectors.

## Guardrails

- Frozen encoders receive no Few-NERD labels.
- No test labels are used to choose encoder, pooling rule, scale set or cache precision.
- Official token boundaries remain the benchmark boundary.
- Exact entity span + fine type remains the primary metric.
- A semantic smoke must verify subword→official-token coverage and deterministic cache reload before any full run.
