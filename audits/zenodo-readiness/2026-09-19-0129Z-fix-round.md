The issue was re-entered despite its `human-review` label because new authorial evidence resolved the exact blocker for which it had been escalated. Scientific/editorial gates were already green from the prior remediation round.

Changes made on branch `automation/zenodo-semantic-atlas-license-20260918`:

1. set `publication.status: ready`;
2. preserved `publication.targets: [zenodo]`, `publication_type: preprint`, `access_right: open`, and version `0.1`;

5. wired that validator into the existing `OKF conformance` workflow so a paper cannot remain marked Zenodo-ready while failing the repository's own packaging contract.

The manuscript body and scientific claims were not changed in this round. A compare against the starting snapshot shows only metadata changes in the paper plus the packaging-validation infrastructure.
