# Pontifex prior-art audit — 2026-09-17

> **Status:** first reproducible replacement for the raw `o3-originality-assessment.md` browsing note. This audit narrows, rather than confirms, the novelty claim. It does not establish legal patent novelty and does not claim exhaustive coverage of the literature.

## 1. Audited claims and cutoff

The audited Pontifex combination is:

1. tokenizer-independent **byte-level occlusion** as a post-hoc attribution unit;
2. **bilateral semantic comparison** using left↔right, left↔original and right↔original similarity signals;
3. parallel probing of multiple **unaligned encoder spaces**;
4. a learned post-hoc **convergence head** over the resulting similarity/agreement patterns.

The earliest public GitHub commit located for those claims is [`4e0ab227169f286a093f8ee2758dba4a4b6bdb0f`](https://github.com/franklinbaldo/papers/commit/4e0ab227169f286a093f8ee2758dba4a4b6bdb0f), dated **2026-05-21**. The commit introduced the Pontifex position paper and explicitly described byte-level occlusion, bilateral comparison, multi-space probing and the convergence head. For the claims above, **2026-05-21 is therefore the current priority cutoff**.

A source first made public after that date is not prior art against these claims in this audit. It may still be recorded as later independent or overlapping work.

## 2. Search protocol

This round searched combinations and decompositions of the claims rather than only the name “Pontifex”. Representative queries included:

- `byte-level occlusion interpretability neural network text saliency`
- `character-level occlusion saliency NLP interpretability`
- `byte-level attribution interpretability transformer`
- `character-level leave-one-out text classifier explanation`
- `tokenizer-free interpretability text byte-level saliency`
- `cross-model consensus explanations interpretability`
- `ensemble explanations agreement across models interpretability`
- `multi-view interpretability multiple models consensus explanations`
- `unaligned embedding spaces explanation consensus`
- `multiple embedding spaces interpretability explanation consensus`

Sources searched in this round included arXiv and ACL Anthology, with source pages used to verify titles and dates. This is not yet an exhaustive IEEE/ACM/Scholar sweep.

## 3. Findings

### 3.1 Occlusion / leave-one-out attribution predates Pontifex

**Classification:** `prior_art` for the generic perturbation-attribution mechanism; **not** prior art for the full Pontifex combination.

Perturbation attribution by removing input features and measuring output change is old. NLP literature before the cutoff explicitly treats leave-one-out deletion as an attribution baseline. A useful pre-cutoff source is:

- Pham, Bui, Mai & Nguyen, **“Double Trouble: How to not Explain a Text Classifier’s Decisions Using Counterfactuals Synthesized by Masked Language Models?”**, AACL 2022. The paper describes the common attribution principle of removing a token and comparing the prediction before and after removal. <https://aclanthology.org/2022.aacl-main.2/>

The 2020 ACL Student Research Workshop also contains Harbecke & Alt, **“Considering Likelihood in NLP Classification Explanations with Occlusion and Language Modeling”**, explicitly describing occlusion as an established explanation method for discrete language data. <https://aclanthology.org/volumes/2020.acl-srw/>

**Effect on Pontifex:** the novelty claim must not be framed as “using occlusion/perturbation for NLP interpretability”. Pontifex inherits an established mechanism and changes the perturbation granularity plus the comparison/aggregation architecture.

### 3.2 Tokenizer-free / byte-level representation predates Pontifex

**Classification:** `prior_art` for operating on bytes without a conventional subword tokenizer; **not** prior art for byte-level post-hoc occlusion.

Before the cutoff there was already substantial byte-level/tokenizer-free modeling literature, including:

- Abonizio et al., **“MonoByte: A Pool of Monolingual Byte-level Language Models”**, COLING 2022. <https://aclanthology.org/2022.coling-1.309/>
- Deiseroth et al., **“T-FREE: Subword Tokenizer-Free Generative LLMs via Sparse Representations for Memory-Efficient Embeddings”**, EMNLP 2024. <https://aclanthology.org/2024.emnlp-main.1217/>
- Deng et al., **“ByteFlow: Language Modeling through Adaptive Byte Compression without a Tokenizer”**, arXiv:2603.03583, first posted 2026-03-03, still before the Pontifex cutoff. <https://arxiv.org/abs/2603.03583>

**Effect on Pontifex:** “tokenizer-free” itself is not a novelty claim. The narrower candidate claim is using raw UTF-8 bytes as the *post-hoc perturbation/attribution unit* for a model that need not itself be byte-level.

### 3.3 Cross-model consensus of explanations clearly predates Pontifex

**Classification:** `partial_prior_art` for the broad idea that agreement among explanations from multiple models can define a more robust explanation; not an anticipation of Pontifex’s unaligned-space scalar-similarity head.

The strongest finding of this round is:

- Li, Xiong, Huang, Ji & Dou, **“Cross-Model Consensus of Explanations and Beyond for Image Classification Models: An Empirical Study”**, arXiv:2109.00707, first posted 2021-09-02. It constructs a committee of models, derives explanations for each model, and obtains a cross-model consensus explanation by voting. <https://arxiv.org/abs/2109.00707>
- Artelt et al., **“One Explanation to Rule them All — Ensemble Consistent Explanations”**, arXiv:2205.08974, first posted 2022-05-18. It formalizes a single explanation intended to be consistent with an ensemble of decisions. <https://arxiv.org/abs/2205.08974>
- Ley et al., **“Consistent Explanations in the Face of Model Indeterminacy via Ensembling”**, arXiv:2306.06193, first posted 2023-06-09. It studies ensemble strategies for improving explanation consistency across alternative models. <https://arxiv.org/abs/2306.06193>

**Effect on Pontifex:** any statement that Pontifex is novel merely because it combines explanations or agreement across multiple models is too broad. The defensible candidate novelty, if it survives further search, lies in the *specific mechanism*: per-perturbation similarity triples from multiple unaligned encoders, aggregated by a learned head without learning a mapping between embedding spaces.

### 3.4 No pre-cutoff source located in this round for the full three-part mechanism

**Classification:** `uncertain_date_or_dependency` / unresolved novelty, not proof of priority.

Within the searches above, this round did **not** locate a pre-2026-05-21 source that combines all of:

1. byte-level post-hoc occlusion;
2. parallel probing of more than two unaligned encoder spaces;
3. a learned convergence mechanism operating over similarity/attribution patterns rather than explicit cross-space alignment.

This is a **negative search result**, not evidence that no such source exists. IEEE, ACM, Google Scholar/Semantic Scholar coverage, patents, theses, non-English literature and broader repository search remain to be completed.

## 4. Later work: temporal classification matters

A later publication can resemble Pontifex without becoming prior art against its May 2026 public claims. For example:

- **“Robust Explanations for User Trust in Enterprise NLP Systems”**, ACL Industry 2026, describes six black-box models, character/word/sentence perturbations and a unified leave-one-out occlusion explainer. Its ACL publication is after the 2026-05-21 Pontifex cutoff. <https://aclanthology.org/2026.acl-industry.81.pdf>

On the evidence reviewed here this belongs, at most, under `later_overlap`: it is temporally posterior and overlaps on black-box multi-model perturbation analysis, but this round found no evidence that it uses Pontifex’s bilateral similarity triples, unaligned multi-space convergence head, or that it derived from Pontifex. **No causal inference is warranted.**

## 5. Revised novelty statement

The old companion-note conclusion “Pontifex is genuinely new” is not supported as written.

A better current statement is:

> Prior work before 2026-05-21 already establishes perturbation/leave-one-out attribution, tokenizer-free byte-level modeling, and cross-model/ensemble consensus of explanations as separate ideas. This audit has not yet located a pre-cutoff source combining byte-level post-hoc occlusion with bilateral similarity signals across multiple unaligned encoder spaces and a learned convergence head over those signals. The novelty of that specific combination therefore remains an open, auditable claim rather than an established fact.

## 6. Next search frontier

Highest-value next queries should target the remaining narrow mechanism rather than repeat generic occlusion searches:

1. learned aggregation of explanation maps across heterogeneous pretrained encoders;
2. consensus over scalar similarity vectors from unaligned latent spaces;
3. multi-model perturbation explainers at character/byte granularity;
4. cross-modal disagreement localization without explicit embedding alignment;
5. patents, theses and pre-2026 GitHub implementations using the same decomposition under different terminology.
